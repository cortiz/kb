## 1. `kb pick`

Runs the compact picker in script or interactive mode.

```
kb pick [QUERY]... [OPTIONS]
```

### Arguments & Options
- `[QUERY]...`: Optional initial query text.
- `--type <TYPE>`: Filter by entry type (`cmd`, `sql`, `sumo`, `cw`, `prompt`, `link`, `code`).
- `--tag <TAG>`: Filter by tag (repeatable).
- `--height <HEIGHT>`: Picker height (`<N>` lines or `<N>%`, default: `40%`, min 10 lines).
- `--no-preview`: Disable the right-hand preview panel even on wide screens ($\ge 120$ cols).
- `--print <MODE>`: Output mode upon pick (`resolved`, `raw`, `id`, `payload`, default: `resolved`).
- `--tmux`: Open inside a `tmux display-popup` if running in tmux 3.2+.
- `--widget`: Internal flag for shell widgets (outputs JSON on stdout).
- `--shell <SHELL>`: Target shell dialect (`zsh`, `bash`, `fish`) when `--widget` is used.
- `--buffer <TEXT>`: Initial command line buffer text.
- `--cursor <N>`: Current cursor byte offset in buffer.

### Exit Codes
- `0`: Pick succeeded, result written to stdout.
- `130`: Cancelled by user (Esc, Ctrl-C).
- `1`: Nothing to pick (empty KB or refused secret without env).
- `2`: Usage or fatal I/O error.

## 2. `kb shell init`

Generates shell definition script to be evaluated in shell profile.

```
kb shell init <zsh|bash|fish>
```

### Output
Prints shell functions:
- Defines `_kb_widget`.
- Binds configured widget key (`Alt-K` default, or `$KB_WIDGET_KEY`).
- Defines `kb-save-last` function and binds `Alt-Shift-K`.
- Loads shell completions for `kb`.

---

## 3. `kb shell install` & `kb shell uninstall`

Installs or removes the `eval "$(kb shell init ...)"` invocation from the user's startup files.

```
kb shell install [--yes]
kb shell uninstall [--yes]
```

### Target Files
- `zsh`: `~/.zshrc`
- `bash`: `~/.bashrc` (Linux) / `~/.bash_profile` or `~/.bashrc` (macOS)
- `fish`: `~/.config/fish/config.fish`

### Block Markers
```sh
# >>> kb >>>
# Auto-generated by kb shell install; edits outside this block will be overwritten.
eval "$(kb shell init zsh)"
# <<< kb <<<
```

## 4. `kb completions`

Prints static shell completion script.

```
kb completions <zsh|bash|fish>
```

## 5. `kb __complete` (Hidden)

Dynamic tab completion handler invoked by shell completion scripts.

```
kb __complete <entries|tags|types|vars|var-values> [ARGS]...
```

### Subcommands
- `kb __complete entries [prefix]`: Returns lines formatted as `<id>\t<title>`.
- `kb __complete tags [prefix]`: Returns matching tag names.
- `kb __complete types`: Returns `cmd`, `sql`, `sumo`, `cw`, `prompt`, `link`, `code`.
- `kb __complete vars <id> [prefix]`: Returns variable names for entry `<id>` formatted as `<name>=`.
- `kb __complete var-values <id> <name> [prefix]`: Returns enum options for `<name>` in `<id>`.
